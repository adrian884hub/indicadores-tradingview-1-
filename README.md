# 🌡️ SR Confluencia + SL/TP + Mapa de Calor — Pine Script

Indicador técnico profesional para TradingView desarrollado en Pine Script v5.

## ¿Qué hace?
- Motor de confluencia que cruza niveles S/R con líneas de tendencia proyectadas
- Cálculo automático de Stop Loss y Take Profit con ratio R:R configurable
- Mapa de calor generativo: itera 60 bandas de precio calculando atracción de cada nivel y colorea por intensidad
- Sistema de scoring multicapa con representación visual por estrellas (★★★)

## Tecnologías
- Pine Script v5
- TradingView
- Desarrollado en colaboración con IA (Claude, ChatGPT)

## Cómo instalarlo
1. Abrí TradingView
2. Entrá al Editor de Pine Script
3. Copiá el contenido de `indicador-sr.pine`
4. Pegalo en el editor y clic en **Agregar al gráfico**
