# SR Confluence + SL/TP + Heat Map, Pine Script

Professional technical indicator for TradingView, written in Pine Script v5.

## What it does
- Confluence engine that crosses support and resistance levels with projected trend lines
- Automatic Stop Loss and Take Profit calculation with a configurable risk-reward ratio
- Generative heat map: scans 60 price bands, measures how strongly each level attracts price and colors it by intensity
- Multi-layer scoring system shown visually with stars

## Built with
- Pine Script v5
- TradingView
- Developed in collaboration with AI (Claude, ChatGPT)
