# 📊 Zonas Rebote + Volumen (ZRV) — Pine Script

Indicador técnico avanzado para TradingView desarrollado en Pine Script v5.

## ¿Qué hace?
- Detección automática de pivotes de soporte y resistencia con algoritmo de scoring propio (1 a 5 puntos)
- Volume Profile de 20 bandas con cálculo de POC, VAH y VAL
- Sistema de señales de compra/venta por confluencia de 3 filtros simultáneos: nivel clave + patrón de vela + volumen
- Reconocimiento de 6 patrones de velas: Engulfing, Hammer, Pin Bar, Shooting Star y más
- Sistema de alertas automáticas con mensajes personalizados

## Tecnologías
- Pine Script v5
- TradingView
- Desarrollado en colaboración con IA (Claude, ChatGPT)

## Cómo instalarlo
1. Abrí TradingView
2. Entrá al Editor de Pine Script
3. Copiá el contenido de `indicador-zrv.pine`
4. Pegalo en el editor y clic en **Agregar al gráfico**
